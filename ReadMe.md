# [[_public]] 

#has_/url_for_/code_repository :: https://github.com/SpocWiki/_public 

 The git Repository https://github.com/SpocWiki/_public should be checked out int this Folder. 
 This works only on Desktops. 
 Due to the Size of the public Repositories, Obsidian becomes very slow! 
30_000 Files seem to be a limit that is hard to exceed. 

This Folder is used to model a public Structure. 
Parallel Folder Structures should mirror this [[_public]] Folder 
to separate secret Information from other [[/_Standards/Confidentiality|Confidentiality]] categories using separate Folders. 

The privacy/confidentiality  hierarchy/order/classification is 
0. Standard
1. public 
2. internal 
3. protected 
4. private 
5. personal 
6. secret
